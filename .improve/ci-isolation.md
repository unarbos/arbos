Public avatar CDN requests may remain: Swift is relay-endpoint isolated, **not** a universal no-egress sandbox.

Linux compilation downloads/builds public dependencies before the network fence. The complete Cargo test command then runs in a fresh network namespace with loopback only, as the original nonroot UID/GID with supplementary groups/capabilities dropped and no-new-privs. Compile/test environments use the same narrow compiler-variable allowlist; tokens, proxies, live-test opt-ins and shell startup hooks are not forwarded. Setup failures have no unfenced fallback. Retained mock contracts establish command behavior; actual kernel smoke and native test verdicts must be observed in CI. This is a network/privilege fence for existing tests, not a filesystem sandbox against arbitrary malicious build scripts.

No release workflow is invoked. The only CI completion listener independently requires a successful original push on main; improve/* fork pushes cannot publish/deploy. CI's image job is hadolint only. Standard public ubuntu-24.04/macos-15 compute is available without a paid runner upgrade; no cache limit/billing setting was changed.
