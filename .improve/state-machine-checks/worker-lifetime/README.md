The actual shared boundary is std-only `worker_lifetime::State<T>`: Accepting with per-session Starting/Ready/Stopping, or terminal Closed. Opaque monotonically allocated tickets bind capture, publication, abort and stop completion; all mutations pass through its one transition function. RpcSessions uses this controller, not a parallel reference model. Streams are attached to the same immutable resource as their child; an observer subscription does not own publication.

A WorkerBoot owns each spawned child before the next cancellable registry/GetState wait. Exact-ticket publication performs existing synchronous session records and publication under one short registry lock; no child await is held there. Failure/cancellation retires only captured children. Shutdown closes admission first and collects both pending and ready resources. Ordinary stop remains reusable: it marks Stopping, exposes unknown liveness while cleanup owns the child, and lets resume wait for that receipt. Notify waits are registered before the state peek, including multiple waiters/cancellation. Stop cleanup is protected by RAII and exact ticket; old boot cleanup cannot clear a replacement. Existing is_open try-lock uncertainty is retained.
