Observed states are Missing, Draft, Prerelease and Stable. A Request carries explicit NoPromote/Publish intent and channel. The single pure transition produces Creating(target) or Uploading(target); upload success requires Finalizing(target), then finalization success produces Complete(target). Typed failure and refusal are terminal and absorbing. Creating a new draft is not representable, preserving the historical new-tag public-prerelease policy. SDK `gh release create` retains responsibility for its existing draft/upload/publish sequence and partial-failure behavior.

NoPromote + Stable refuses before a create/upload/edit or channel-feed write. NoPromote + Draft preserves draft status and reports staged completion. Missing + NoPromote remains a public prerelease. Publish + Draft explicitly undrafts and chooses stable or edge prerelease/latest flags. The existing stable promoted-refresh path remains allowed. Confirmed baseline illegal combinations were public-stable candidate overwrite and a successful promoted draft retry that remained draft. Three positive baseline controls passed while those two regressions failed.

The stdlib Python seam fits the existing Bash/Python release runtime and adds no package installation or Effect dependency to release hosts. Pure transition tests pin terminal absorption (48 deterministic state/event combinations), refused/failed completion behavior and finalization ordering; three Schema-derived laws additionally cover 768 seeded traces and a real-function mutation is detected, shrunk once and replayed; the actual wrapper/fake-GH cases pin effects and receipts. No state-only model substitutes for publisher execution.
