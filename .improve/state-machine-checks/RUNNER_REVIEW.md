# Independent H9 review

Scoped review PASS, with no outstanding actionable defect found in the frozen runner candidate. This review inspected the actual request/lease/GUI/boot transitions, callers and tests; it does not imply a live Mac runner or simulator trial.

The effectful admission and GUI attempts execute in the requester shell with a function-scoped inherited FD9. The kernel lock inode is distinct from removable lease records. No queue sleep holds the short lock. Heavy staging is hidden, metadata is validated before publication, the owner is observed before and after publication, and ownership is recorded before the rename so a deferred TERM can retire the published lease. Cleanup remains conservative if both retirement marking and deletion fail. Boot checks reject retired, malformed, dead and unpublished observations. GUI renewal rollback compares the exact published inode and restores the hard-linked prior record, including its mtime, rather than deleting a replacement.

Earlier independent review found a real deferred-signal leak in effectful command substitution, a failed-retirement capacity hole, and cancellation of GUI renewal that could lose the prior lease. The author retained failing-before cases and fixed these boundaries. The final adapter evidence records 34 passing cases in 15.980 seconds, three Bash syntax checks, and identical before/after hashes. I did not duplicate that broad subprocess suite after source freeze.

Independent generated validation: four Schema/Arbitrary laws, 256 cases each (1,024 total), plus one protocol-recovery test pass. Both actual-function negative controls are falsified with one accepted shrink and exact replay: `InvalidHeld` returning zero capacity, and `Explicit:Retired` producing an authorization event. The ordinary unmodified suite includes successful grant/GUI/retirement/boot controls to prevent vacuous refusal-only success. Source extraction is fail-closed on missing/duplicate function definitions; requests/replies and execution time are bounded.

Limits: the laws use finite generated domains and a deterministic canonical shrink; they are not an exhaustive proof or a general-purpose shell sandbox. The bridge deliberately supports only the listed actual pure definitions, never arbitrary shell input. Original priority, FIFO, timeout, release-exemption and simulator calibration remain in the separately tested adapter paths; no scheduler policy change is inferred from these properties.
