# P-05 rewind: per-turn checkpoints, `arbos-kernel rewind`

Branch `cursor/rewind-b027` (on `cursor/release-integration-52cd`). Kernel side of "rewind to a turn with file state"; no desktop button yet.

- Turn start writes `<agent>/checkpoints.jsonl`: `{line, ts, head, work?}` — `work` is a `git stash create` commit of the working tree (absent when clean), kept alive by `refs/arbos/cp/<agent>/<line>`.
- `arbos-kernel rewind <place> --list` lists turns (line, time, head, `+wt` when a tree was saved, opening words). `--to LINE` / `--back N` cut the transcript at that turn's start (cut lines archived to `transcript.rewound-<ts>.jsonl`), trim the checkpoints, and with `--files` reset HEAD, `git read-tree -u --reset` the saved tree (changes come back unstaged, as they were), `git clean -fd -e .arbos`. Asks `proceed? [y/N]` unless `--yes`. Refuses while a kernel serves the place (its tail would replay the shrunken file to every window).

Verified: two turns (`v1 > a.txt`; then `v2 > a.txt; new > b.txt`, both uncommitted) → `--back 1 --files` → `a.txt` is `v1` unstaged, `b.txt` gone, transcript 12 → 7 lines, archive written, `refs/arbos/cp/root/8` present.

Attack surface: a place that is not a git repo (`--files` should say so, transcript still cut); a turn that committed (HEAD moved) — the checkpoint's `head` is the pre-turn commit, `reset --hard` drops the commit from the branch (it stays reachable via reflog; say if that should refuse instead); untracked files that existed before the turn are removed by `clean` (same as `undo` today — the design's open question 5); `--to` a line that is not a turn start (refused with `see --list`); sub-agent worktrees (`cwd` under `.arbos/worktrees/…`) — restore runs in the agent's cwd; a rewind of `root` does not touch children's transcripts or worktrees; old transcripts have no checkpoints (clear error); rewind then restart the kernel: the desktop reloads from files — check it shows 7 lines, not 12, and that QA's `TranscriptTail` offset store (if any persisted) does not confuse a shorter file.
