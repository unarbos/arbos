# P-04 memory across sessions — QA note (features agent, 2026-09-13)

Branch `cursor/memory-b027`, base `rust`.

## What it does

- `remember` tool: `text` (required), `scope` = `place` (default, `.arbos/memory.md`) or `user` (`~/.config/arbos/memory.md`, every place), `op` = `add` (default) or `forget` (removes the lines containing `text`). Each memory is one line `- text` under a `# Memory` heading. Exact duplicates are not added twice. A file past 200 lines refuses new adds and tells the model to `forget` or consolidate.
- Prompt: the instance prompt shows `Memory (.arbos/memory.md):` and `Memory (user, …/memory.md):` blocks after AGENTS.md, clipped like AGENTS.md. Empty or missing files show nothing.
- CONTRACT line tells the model what belongs there (durable facts about the project or the user, decisions, preferences) and what does not (task progress → plan; secrets → never).
- The file is a plain markdown file the user can edit; `read`/`edit` work on it too.

## Attack ideas

1. `remember` text containing a newline: stored as one line? Newlines are replaced with spaces. Check.
2. `remember` an API key value: nothing stops it today except the CONTRACT sentence. With #30 (secrets door) the value would be redacted in the tool result but still land in the file. Note as a gap; propose: refuse texts that match a protected secret when #30 lands.
3. 201st memory: refused with the consolidate hint; `forget` of a substring hitting several lines removes all of them and says how many.
4. `scope=user` from a readonly agent: `remember` is a writing tool, so readonly agents lose it — confirm the allowlist drops it.
5. Two agents `remember` at the same moment: appends are separate `OpenOptions::append` writes; lines should not interleave (one write per line).
6. Memory file with a user's own headings and prose: `add` appends at the end; `forget` only removes lines containing the text; headings stay.
7. Prompt size: a 16 KB memory file gets `evict_head` treatment (same as AGENTS.md); check the cite lets the model `read` the rest.
8. Remote place (host set): `~/.config/arbos/memory.md` is the kernel machine's, not the desktop's. Expected.
9. `forget` with empty text: refused.
10. Compaction: the memory block is in the instance prompt (system), so it survives context checkpoints — verify after a `/compact`.

## How to run

```
arbos-kernel run . 'remember that this project uses uv, never pip; then reply ok'
cat .arbos/memory.md
arbos-kernel run . 'without tools: what package manager does this project use?'
```
