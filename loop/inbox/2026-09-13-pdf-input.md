# PDF input — PR #109, branch `cursor/pdf-input-b027`

- `read <file>.pdf` → text with `--- page N ---` markers, numbered lines, `offset`/`limit` paging. Needs `pdftotext` (poppler) or `mutool`; without them the tool says which package to install.
- A `.pdf` in a prompt's `attachments` is inlined as text (cap 40 000 chars, then "read the file for the rest").

## Scenario ideas

- Drop a PDF on the desktop composer with "summarise this" → the model answers with no `read` call (the text was inlined); a 200-page PDF → the cap note appears and the model reads with `offset`.
- A scanned PDF (images only) → `pdftotext` returns empty text; the model should say the PDF has no text layer. Worth a fixture: does it hallucinate content?
- A file named `.pdf` that is not a PDF → `pdftotext` fails with its first stderr line in the tool error.
- Uninstall poppler in a container → the error names the package.
